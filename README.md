# WearWifiTools

WearWifiTools is a comprehensive WiFi analysis and debugging utility for Wear OS smartwatches.

## Features
- Real-time local Wi-Fi network scanner and signal strength (RSSI) monitor\n- Detailed connection state, IP address, and Gateway details\n- AMOLED UI design optimized for round smartwatches

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.
